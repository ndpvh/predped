# Default supermarket

This variable contains the default supermarket used in the benchmarks
and and tests, as well as some substantive studies. The supermarket is
coded as an instance of the
[`background-class`](https://github.com/ndpvh/predped/reference/background-class.md)
and is based on the blueprints of an Albert Heijn supermarket based in
Amsterdam.

## Usage

``` r
supermarket
```

## Format

Instance of the
[`background-class`](https://github.com/ndpvh/predped/reference/background-class.md)
