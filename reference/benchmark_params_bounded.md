# Benchmarked parameters (bounded)

This data.frame contains a set of bounded parameters used to benchmark
the parameter-related functions.

## Usage

``` r
benchmark_params_bounded
```

## Format

A data.frame with the rougly the same columns as the archetypes
datasets, see
[`load_parameters`](https://github.com/ndpvh/predped/reference/load_parameters.md)
