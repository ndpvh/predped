# Transform a list of states to a trace

Transform a list of states to a trace

## Usage

``` r
state_to_trace(states, ...)
```

## Arguments

- states:

  List of objects of the
  [`state-class`](https://github.com/ndpvh/predped/reference/state-class.md)

- ...:

  Additional arguments defining the `id` or `time_step` to be maintained
  in the trace.

## Value

Object of the
[`trace-class`](https://github.com/ndpvh/predped/reference/trace-class.md)

## See also

[`state-class`](https://github.com/ndpvh/predped/reference/state-class.md),
[`trace-class`](https://github.com/ndpvh/predped/reference/trace-class.md)
