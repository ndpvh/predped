# Trace used in benchmarks

This variable contains an instance of the
[`trace-class`](https://github.com/ndpvh/predped/reference/trace-class.md)
that serves in the benchmarks for testing data handling functions.

## Usage

``` r
benchmark_trace
```

## Format

Instance of the
[`trace-class`](https://github.com/ndpvh/predped/reference/trace-class.md)
