# Initial condition used in benchmarks

This variable contains an instance of the
[`state-class`](https://github.com/ndpvh/predped/reference/state-class.md)
that serves as an initial condition in the benchmarks.

## Usage

``` r
benchmark_inx
```

## Format

Instance of the
[`state-class`](https://github.com/ndpvh/predped/reference/state-class.md)
